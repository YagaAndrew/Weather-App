# 🌤️ Weather App

A simple web-based weather application built to display real-time weather information for various cities around the world. This project was created as a practical exercise to deepen my understanding of **Front-End Development**, specifically in performing *API fetching* and DOM manipulation using pure JavaScript.

---

## 🚀 Key Features

*   **City Search:** Search for weather data based on the city name entered by the user.
*   **Real-time Weather Info:** Displays temperature (in Celsius), weather conditions (cloudy, rainy, clear, etc.), humidity, and wind speed.
*   **Responsive Design:** A clean and comfortable layout optimized for both *mobile* and *desktop* devices.
*   **Dynamic Weather Backgrounds:** (Optional, remove if not applicable) Backgrounds or icons that dynamically change to match the current weather conditions.

---

## 🛠️ Technologies Used

*   **HTML5:** For building the semantic structure of the web pages.
*   **CSS3:** For layout (layouting) and *styling* to create an attractive, responsive interface.
*   **Vanilla JavaScript (ES6+):** For application logic, handling events, and *fetching data* from the API.
*   **Weather API:** Powered by the [OpenWeatherMap API / or specify the API you used] to fetch up-to-date weather details.

---

## 📖 What I Learned from This Project

This project has been incredibly helpful in sharpening my front-end skills, including:
1.  **Asynchronous JavaScript:** Understanding concepts like `fetch`, `async/await`, and how to handle *promises*.
2.  **API Integration:** Learning how to send *requests* to a third-party server using an *API Key* and processing the received JSON response.
3.  **DOM Manipulation:** Dynamically updating HTML elements based on the weather data successfully retrieved.
4.  **Error Handling:** Managing scenarios when a city is not found or when network issues occur to ensure the app doesn't *crash*.
